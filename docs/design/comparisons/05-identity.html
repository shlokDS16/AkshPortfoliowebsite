Segment 5: identity

Three identities for the same desk, applied to the decided screens: the register home with What changed (segment 2), the B+ Kaveri file (segment 1), the segment 3 exhibit frame, a 1200 × 630 share card and a 32 px favicon. Every mock is one component set. Only the tokens, the wordmark, the mark and the micro-copy change, so the comparison is about identity and not about layout.

The rule in all three: the accent is for the hand, ink is for the data. The accent marks links, focus, the active tab and the mark. It never colours a figure, a status or a chart series. Statuses stay ink shapes (filled, half, open, dashed). Charts use ink for the subject, grey for the benchmark and one separate data hue for thresholds. Contrast ratios below are computed live from the tokens. Companies, symbols, figures and dates are invented.
