Segment 1: reading experience, three directions

Each direction renders the same thesis page from one shared data object, so only the design differs. The company, ticker and every figure are fictional and are there to test layout. Colour is a placeholder (greys plus one muted accent). Identity is decided in segment 5, so judge type, measure, hierarchy and how each block is marked, not palette.

Each desktop frame is 960 px wide and each phone frame 375 px. Both scroll on their own. Layout switches on the frame's own width (container queries), so the phone shows the real mobile layout.

Layout
A

A. Margin Ledger

Aksh's argument keeps the full column. Every citation, as-of date and revision mark sits beside the sentence it supports, so the reader can check a claim without leaving it.

B

B. Labelled Blocks

The page reads like a well-kept research file. Every block says what it is (VIEW, TEST, FACT), facts and kill criteria are rows you can scan, and revisions show as a diff.

C

C. Letter and Exhibits

The thesis reads as a dated letter from Aksh. Facts appear as numbered exhibits, revisions as signed postscripts, and the disclosure comes before the first word.
