Segment 2: navigation and information architecture

Three ways to organise the public desk, and to move around it, on a phone and on a desktop. Each frame is a working mock: tap links inside it to move between the desk home, the company index, the Kaveri file, a learning note and the menu or search. Every company link opens the Kaveri file, the only full file in the mock. Companies, symbols, figures and dates are invented to test layout.

The Kaveri file is the decided B+ page from segment 1, unchanged inside. Only the chrome around it changes: what sits above it, beside it and below it, and where the learning notes and the disclosure go. Colour stays neutral grey, because identity is segment 5.

A. The Register

The desk is a register of files: every company listed with its version, last revision, test status and data date, so a reader audits the desk before reading any of it.

Home is the file index · tab bar on phone, one left rail on desktop · breadcrumbs plus a rail that opens into the file's own sections · notes linked as a "used in" table

B

B. The Desk Log

The desk is a dated log of what changed and why; search is the only navigation, and every company, note and test is one query away.

Home is the change log · search in a bottom dock on phone, a search field on desktop · no breadcrumbs · notes open inline from the words that use them

C

C. The Weekly Letter

The desk reads like a periodical: home is this week's short letter from Aksh, the files sit behind it grouped by sector, and one Contents page maps everything.

Home is a dated letter · one Contents button, top right, on every screen · a sector kicker instead of breadcrumbs · notes placed before the file as "read first"
