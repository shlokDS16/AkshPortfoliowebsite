Segment 4: capture and review (the private /desk)

Three directions for the screens only Aksh sees: (1) the desk home with one capture box, (2) the item editor with the publish gate, (3) the document inbox, (4) the review screen and (5) the new-names list. Each direction uses the decided B+ type system (IBM Plex Sans, with Plex Mono for IDs and grammar tokens), the segment-3 placeholder blue and the segment-3 meter. All companies, symbols, figures, links and notes are invented to test layout.

Try the capture box in any frame: type t: $KAVERIPM receivables up again #working-capital and press Enter (Shift+Enter for a new line). The grammar is parsed as you type; unknown symbols such as $LOHITGLS show as new names. Switch State to see the offline queue and the red liveness strip. On screen 2, try "Allow this sentence" on sentence 7.

A

A. Command line

One prompt that reads the grammar as you type and answers with a one-line receipt; a plain log of today; every review screen works from number keys.

References: Raycast, Linear Triage, Superhuman, Todoist Quick Add, the Kite order window, Prodigy. On a phone the prompt docks above the tab bar with a key row for $ # t: l: p:, where the thumb already is.

B

B. Day book

Every day is a page. Aksh writes the next line; the desk files it quietly and answers in plain sentences, the gate included.

References: Drafts, Bear, Apple Notes, Notion and Obsidian mobile, Google Keep. On a phone the date and the next line sit at the top, and each gate note sits directly under the sentence it is about.

C

C. Trays

The desk is a set of trays: what needs Aksh, what is being read, what came in today. Capture is one button on every screen; review is one decision at a time.

References: HEY (Screener, Imbox), Things Today, Linear Triage, Readwise Reader, Lightroom flags, Label Studio. On a phone the Capture button sits above the tab bar and opens a sheet with the keyboard already up.
