Segment 6: motion, three personalities on the same two screens

Each personality runs on the decided screens: the register home with its "What changed" block (segment 2) and the B+ Kaveri file (segment 1). The markup, type and greys are identical in all six frames; only motion differs. Every frame is a working mock: open the Kaveri file from the register, open the strip, tap a source chip such as S1 · p. 112, scroll to the tests, the facts and the history, sort and search the register, and press Replay under any frame to watch its entrance again.

Under each frame, Skeleton loads the screen from a skeleton and Empty swaps in a first-day desk or a first draft. The Motion switch below degrades every animation in every frame to instant or opacity-only; it starts on your system setting. Each personality ends with a spec panel whose durations and easings can become tokens. Built with CSS and the Web Animations API only: no animation library and no CDN script, so it opens from disk. The chart in the Facts block is a placeholder (segment 3 is not decided) that exists to carry chart motion. Company, figures and filing lines are invented.

Layout
Motion
1

Instrument

The desk behaves like a precise instrument: controls snap, statuses tick, counts roll like an odometer, and reading content never fades in.

Verbs: snap, tick, roll. 120 to 220 ms, one easing, no overshoot. Real build: CSS + Motion (LazyMotion) + NumberFlow.

2

Paper

The desk behaves like a well-set periodical: the company name carries you into its file, blocks settle in once, and revisions are marked the way an editor marks proof.

Verbs: glide, draw, settle. 160 to 300 ms, a long-tailed ease-out. Real build: React ViewTransition + CSS + Motion.

3

Terminal

The desk behaves like a data terminal: figures count in, lines draw up to the 30-day data cap and stop, and every interaction answers instantly.

Verbs: draw, count, stamp. 0 ms for feedback, up to 280 ms for data, linear or stepped. Real build: CSS scroll-driven animation + NumberFlow + SVG pathLength.
