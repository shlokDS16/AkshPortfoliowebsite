Segment 3: data display

Three directions for the figures inside the B+ file and on the register home, all on one fictional company, Kaveri Pumps & Motors. Each direction shows (1) a five-year table, (2) the public scenario table, (3) a receivable-days chart and a lagged price line against the Nifty 50, (4) the home stat tiles and the kill-criteria table as data, and (5) the private valuation panel. Company, figures, prices and quoted lines are invented to test layout.

Chrome, type and greys are the decided B+ and Register system. One blue is a placeholder data accent so charts can be judged; segment 5 sets the real colour. Hover or focus a chart and use the arrow keys for values; tap a dotted figure or a source chip to open its source card.

A

A. Ledger

The table is the exhibit. Periods run across as in an annual report, each column says when it ends and where it came from, and charts stay small enough to sit beside the table.

References: Screener, StockAnalysis, Damodaran, annual-report notes. On a phone the years become a sticky five-column key and each metric becomes a row under it, so nothing scrolls sideways.

B

B. Exhibits

Every figure block is a numbered exhibit: a plain-fact title, the chart first, the table one tap away, and a source-and-date footer fixed to the chart.

References: Our World in Data, FRED, Observable Plot, broker-report exhibits. On a phone the five years become small multiples, each with its own scale, and the table sits behind the Table tab.

C

C. Instrument rows

One row per measure, read in a second: a label, a sparkline and the latest value with its date. Tap the row and the five years, sources and quoted line open in place.

References: Koyfin, Stripe and Linear dashboards, GitHub Insights, Google Finance. On a phone the rows already fit; the detail opens downward as a list of periods.
