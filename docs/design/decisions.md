## Segment 6: motion (pulled forward at Shlok's request)
- **Options shown (2026-10-05):** Instrument (snap/tick/roll, 120-220 ms, one ease-out), Paper (glide/draw/settle, 160-300 ms, shared-element morph), Terminal (draw/count/stamp, instant feedback). `comparisons/06-motion.html` (CSS + Web Animations API, no library; CLS 0 measured), brief `segment-06-motion-brief.md`. Tokens: durations 120/180/220 ms, easing cubic-bezier(0.2,0,0,1), steps(4) for status ticks, press scale(0.97), no overshoot; reading content never fades; h1/LCP never animates.
- **Build stack (from brief table):** CSS transitions for hover/press/focus; React `<ViewTransition>` for row-to-title; Motion 14 via LazyMotion/m for strip, source cards, layoutId index indicator, tab-bar hide; NumberFlow for counts (never on financial figures); CSS pathLength/stroke-dashoffset or Recharts `isAnimationActive="auto"` for draw-to-cap; CSS `animation-timeline: scroll()` with @supports + JS fallback for the hairline. No GSAP, no Lenis. Reduced motion: `MotionConfig reducedMotion="user"` + CSS `prefers-reduced-motion` + `::view-transition-*` rules.

## Task 11 (Plan 3a): the Closes page, the official-file drop, corporate actions, the journal
- **Options:** none shown. Shlok delegated the design and the owner publishes tomorrow; nothing here is decorative. Every pick below is a **controller-delegated pick, pending Shlok's approval** (2026-10-14).
- **One page, sections in the order the work goes:** how current the closes are and what the last runs said, the recent days, "Fetch closes now", "Drop NSE's official file", "Type a close", the closes that are not NSE's own fetch, the scores restated lately, then corporate actions. Each section is a heading with a rule above it, no cards, no tabs: a long page with anchors beats a second navigation level on a phone.

The date field is a native date input limited to today.
- **Corporate actions: correct, never edit.** A "Correct this entry" link on each entry in force opens the same form from that entry with the company fixed; replaced entries stay listed below, dimmed and labelled "Replaced by a later entry". The factor is explained in one sentence above the form, with the 1:5 example the plan asked for.
- **The journal is a plain ordered list** with a left rule like the idea page's entries, so the same words look the same in both places. No grid (the owner cut it), no chart, no export.
- **The strip line stays quiet:** the failed public-copy run is a note in the existing quiet status line, not a second alert, because the latest run is green and nothing needs doing; it ages out after 30 days.
- **Ledger page:** two plain links under the title ("Closes and corporate actions", "What I learned"), not new tabs, so the five-tab phone bar is unchanged.
