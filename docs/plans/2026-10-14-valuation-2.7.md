# 2.7 Valuation models (XLSX -> confirmed cells -> private scenarios) Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development (or executing-plans) task by task. Steps use `- [ ]`.

**Status:** written 2026-10-14 on branch `phase-2.7-valuation` (from `main` dff5ee8). **Spec:**
`docs/specs/2026-10-14-valuation-2.7-design.md` (s3 libraries, s4 security, s5 pipeline, s6 data, s7 page, s8 states, s12
decisions D1-D20). Binding: ADR-001 s3/s4/s8.4, `docs/compliance/publishing-rules.md` rule 9, Phase 2 spec s4/s6.2/s7/s8,
ADR-004.

**Goal:** Aksh drops a `.xlsx` with a `$SYMBOL` in the inbox; a job reads it safely, recomputes it with HyperFormula and
lists every formula that disagrees with Excel; he confirms which cells are inputs and which are results; then on
`/desk/models/[versionId]` he moves inputs, sees scenario outputs and a sensitivity grid, and saves named scenarios. Nothing
is public, nothing calls an LLM, nothing overwrites the workbook.

**Architecture:** new module `src/modules/valuation/` (pure core + repo/service/actions + `client.ts`), one new job kind
`ingest_xlsx` with one step `xlsx_read` registered in `src/modules/ingestion/steps/index.ts` (ingestion -> valuation, never the
reverse), migration 0016, two routes under `/desk/models`, HyperFormula lazy-loaded on that route only.

## Global constraints
- **Rule 9:** `anon` gets nothing from this plan; `src/app/(public)/**`, `src/modules/showcase/**` and
  `src/modules/compliance/**` never import `@/modules/valuation` (`valuation.graph.test.ts`).
- **The AI organises, Aksh thinks:** machine data (grid, classes, taint, suggestions, sheet labels) only in the grid JSON and
  the version's machine columns; his labels, names, notes, roles and input values only in `valuation_cells`,
  `valuation_scenarios`, `valuation_scenario_values`. Never pre-fill his label field with sheet text (D11).
- **Imports:** `xlsx` only in `src/modules/valuation/read-workbook.ts` (`import "server-only"`); `hyperformula` only in
  `src/modules/valuation/engine.ts`. No `LlmPort`, `OcrPort`, `TranscriberPort` in the module. `zip-one.ts` untouched.
- **Dependencies:** exactly two new runtime deps, pinned: `xlsx` from `https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz` and
  `hyperformula@3.5.0`. Never the npm-registry `xlsx`. Re-verify both versions on the day of Task 1 (spec s3).
- **Caps** live in `src/modules/valuation/limits.ts` (browser-safe) with the spec s4 numbers; a change needs a spec edit.
- Files under 300 lines; modules imported through `index`, `actions` or `client`; plain words in every string; the banned
  words of spec s7.3 never in this module's copy. TDD: the failing test is seen to fail first. Never two implementers at once.
- Migrations local only; never edit one after it reaches hosted; `pnpm db:types` after 0016. Supabase CLI via `pnpm supabase`.
- `defenso guard_code` on Tasks 1 and 2 (if its server is down, the opus review stands in, as in Plan 3a).

### Task 1: The workbook core (pure, no database)
Build: `desk-backend` (sonnet). Review: **opus** (hostile input). Size: 350k + 180k.

**Files.** Create in `src/modules/valuation/`: `limits.ts`, `types.ts` (`Grid`, `GridCell`, `CellClass`, `Report`,
`Suggestion`), `zip-scan.ts` (multi-entry scanner on `node:zlib`, the `zip-one.ts` rules per entry plus the spec s4.3-s4.4
caps and refused parts; returns `{ ok: true, parts } | { ok: false, code }`), `read-workbook.ts` (server-only; magic bytes,
`zip-scan`, SheetJS `read` with the spec s3 options, caps of s4.5, grid build), `engine.ts` (build HyperFormula from a
grid with `licenseKey: "gpl-v3"` and the Excel-compatibility options; `valuesOf(addrs)`, `withInputs(overrides)`,
`dependentsOf`), `diff.ts` (classes and taint, spec s5.4), `suggest.ts` (inputs, outputs, sheet labels, carry-forward match,
spec s5.5 and s7.2), `format.ts` (value by Excel format `z`, percent-unit editing), `sensitivity.ts` (steps and the 5 x 5 /
3 x 3 grid). Create `scripts/fixtures/make-models.ts` (writes `e2e/fixtures/model-small.xlsx`: 3 sheets, a tiny DCF with
cached values, one deliberately stale cached value, one function HyperFormula does not register (pick it from
`HyperFormula.getRegisteredFunctionNames` at generation time), one `TODAY()`, one two-cell loop). Modify `package.json`
(+ lockfile).

**Tests first** (`src/modules/valuation/*.test.ts`):
- zip-scan: archives built in the test: a lying declared size (inflates past it) refused; sum over 60 MB refused; 1,001 entries
  refused; zip64, encrypted, method 12 refused; `xl/vbaProject.bin`, `xl/externalLinks/externalLink1.xml`, `xl/activeX/x.xml`,
  `xl/connections.xml`, a macroEnabled content type each refused with its own code; drawings and media ignored; CFB magic
  `D0 CF 11 E0` -> `password_or_xls`.
- read-workbook: formula text and cached value per cell; shared formulas come out per cell; `_xlfn.` stripped; HTML never
  produced; 31 sheets, 100,001 cells, 20,001 formulas, a 8,193-character formula, an external defined name each refused; a
  2,001-character string cut and marked; the installed `xlsx` version is >= 0.20.3 (reads `xlsx/package.json`).
- engine: cross-sheet references and defined names compute; `withInputs` changes a dependent and leaves the grid untouched;
  1904 workbook dates.
- diff: each class (`match`, `differs`, `unsupported`, `cycle`, `no_cache`, `random`, `dated`); tolerance at the edge
  (`1e-9` relative passes, `1e-6` fails); taint reaches a result three steps downstream and not a sibling.
- suggest: inputs ranked by dependents; tainted outputs excluded; sheet label from the left, else above; carry-forward
  pre-ticks only an unchanged constant with the same label.
- format and sensitivity: `0.0%` shows 11.5% and edits as 11.5; step defaults (0.5 pt, 5%); 3 x 3 under 480 px.
- **Measurement (not a pass/fail unit test, a script run once):** generate an at-cap workbook (100,000 cells, 20,000
  formulas) and record read + engine + diff time and peak heap in the task report. Over 60 s or 1 GB: lower the caps in
  `limits.ts` and spec s4.5 in the same commit.

**Acceptance:** `rtk pnpm test src/modules/valuation` green; `rtk pnpm typecheck` and lint clean; the fixture opens in Excel
or LibreOffice (controller eyeballs once); measurement recorded; `defenso guard_code` on `zip-scan.ts` and `read-workbook.ts`.
