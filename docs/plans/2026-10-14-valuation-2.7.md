# 2.7 Valuation models (XLSX -> confirmed cells -> private scenarios) Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development (or executing-plans) task by task. Steps use `- [ ]`.

**Status:** revision 2, 2026-10-14, branch `phase-2.7-valuation` (from `main` dff5ee8). Revision 1 (73b0781) used
HyperFormula; Q37 was answered (b): no GPL code. Engine is now IronCalc (`docs/architecture/ADR-001-addendum-2026-10-14-no-gpl.md`);
the migration is **0017** (0016 is the pump clock, PR in flight). **Spec:** `docs/specs/2026-10-14-valuation-2.7-design.md`
revision 2 (s3 libraries, s4 security, s5 pipeline, s6 data, s7 page, s8 states, s12 decisions D1-D24). Binding: ADR-001
s4/s8.4 and the addendum, `docs/compliance/publishing-rules.md` rule 9, Phase 2 spec s4/s6.2/s7/s8, ADR-004.

**Goal:** Aksh drops a `.xlsx` with a `$SYMBOL` in the inbox; a job reads it safely, recomputes it with IronCalc and lists
every formula that disagrees with Excel; he confirms which cells are inputs and which are results; then on
`/desk/models/[versionId]` he moves inputs, sees scenario outputs and a sensitivity grid, and saves named scenarios. Nothing
is public, nothing calls an LLM, nothing overwrites the workbook.

**Architecture:** new module `src/modules/valuation/` (pure core, server reader, repo/service/actions, `client.ts`), one job
kind `ingest_xlsx` with one step `xlsx_read` registered in `src/modules/ingestion/steps/index.ts` (ingestion -> valuation, never
the reverse), migration 0017, two routes under `/desk/models`, the IronCalc wasm lazy-loaded on that route only.

## Global constraints
- **Licences:** permissive only (MIT, Apache-2.0, BSD, ISC). No GPL, LGPL, AGPL or source-available package, runtime or dev.
  A unit test reads the lockfile's licence fields for the new packages; the reviewer checks any other added dependency.
- **Rule 9:** `anon` gets nothing; `src/app/(public)/**`, `src/modules/showcase/**`, `src/modules/compliance/**` never import
  `@/modules/valuation` (`valuation.graph.test.ts`).
- **The AI organises, Aksh thinks:** machine data only in the model object and the version's machine columns; his labels,
  names, notes, roles and input values only in `valuation_cells`, `valuation_scenarios`, `valuation_scenario_values`. Never
  pre-fill his label field with sheet text (D11).
- **Imports:** `xlsx` only in `src/modules/valuation/read-workbook.ts`; `@ironcalc/nodejs` only in `src/modules/valuation/engine-node.ts`
  (both `import "server-only"`); `@ironcalc/wasm` only in `engine-client.ts` and `tokens.ts`. No LLM, OCR or transcriber port in
  the module. `zip-one.ts` untouched.
- **Dependencies, exact pins:** `xlsx` from `https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz`, `@ironcalc/nodejs@0.8.3`,
  `@ironcalc/wasm@0.8.4` (not 0.8.3: it is missing a file). Never the npm-registry `xlsx`. Re-verify on the day of Task 1.
- **Caps** in `src/modules/valuation/limits.ts` (browser-safe) with the spec s4 numbers; a change needs a spec edit.
- Files under 300 lines; modules imported through `index`, `actions` or `client`; plain words; the banned words of spec s7.3
  never in this module's copy. TDD: the failing test is seen to fail first. Never two implementers at once.
- Migrations local only; never edit one after it reaches hosted; `pnpm db:types` after 0017. Supabase CLI via `pnpm supabase`.
- `defenso guard_code` on Tasks 1 and 2 (if its server is down, the opus review stands in, as in Plan 3a).

**Files.** Create in `src/modules/valuation/`: `limits.ts`; `types.ts` (`SheetIndex`, `IndexCell`, `CellClass`, `Report`,

raw values and types, `toBytes`, delete in `finally`); `tokens.ts` (wasm `initSync` from the package file in Node; references

`diff.ts` (classes, spec s5.4, by `getCellType`, never by string); `suggest.ts` (inputs, outputs, sheet labels, carry-forward);
`format.ts` (Excel format `z`, percent-unit editing); `sensitivity.ts` (steps, 5 x 5 / 3 x 3); `engine-client.ts` (browser-safe
wrapper over `@ironcalc/wasm`: `load(bytes, init)`, `setInputs`, `readResults` through the full-precision format of spec D24).
Create `scripts/fixtures/make-models.ts` (writes `e2e/fixtures/model-small.xlsx` with SheetJS: 3 sheets, a tiny DCF with saved
values, one deliberately stale saved value, `CUBEVALUE` or another function IronCalc returns `#N/IMPL` or `#NAME?` for (checked
at generation), one `TODAY()`, one two-cell loop, one `INDIRECT`). Create `scripts/copy-ironcalc-wasm.ts` (copies
`wasm_bg.wasm` to `public/vendor/ironcalc-0.8.4.wasm`; `postinstall`). Modify `package.json` (+ lockfile), `next.config.ts`
(`serverExternalPackages: ["@ironcalc/nodejs"]`; add `outputFileTracingIncludes` for the wasm file if the job route needs it
for `tokens.ts`; verify both option names in the Next 16.3 docs in `node_modules/next/dist/docs` first).

**Tests first** (`src/modules/valuation/*.test.ts`):
- zip-scan: archives built in the test: a lying declared size refused; sum over 60 MB refused; 1,001 entries refused; zip64,
  encrypted, method 12 refused; `xl/vbaProject.bin`, `xl/externalLinks/externalLink1.xml`, `xl/activeX/x.xml`,
  `xl/connections.xml`, a macro-enabled content type each refused with its own code; drawings and media ignored; `D0 CF 11 E0`
  -> `password_or_xls`.
- read-workbook: formula text and saved value per cell; shared formulas per cell; `_xlfn.` stripped; no HTML; 31 sheets,
  100,001 cells, 20,001 formulas, an 8,193-character formula, an external defined name, a 1904 workbook each refused; a
  2,001-character string cut and marked; installed `xlsx` >= 0.20.3; the three new packages' licences are MIT or Apache-2.0.
- engine-node + engine-client: the fixture's NPV/XNPV/INDEX-MATCH/INDIRECT cells compute; `toBytes` from Node 0.8.3 loads in
  wasm 0.8.4 and gives the same value for every formula cell (the version-skew guard); a changed input moves a dependent; the
  full-precision readback equals the Node raw value to 15 significant digits; the temp file is gone after success and after a
  thrown error.
- graph and diff: each class (`match`, `differs`, `unsupported`, `cycle`, `no_cache`, `random`, `dated`); tolerance edges
  (`1e-9` relative passes, `1e-6` fails); taint reaches a result three steps downstream and not a sibling; a range `A1:A5` and a
  sheet-qualified reference are edges; an `INDIRECT` cell is `dynamic`.
- suggest, format, sensitivity: ranking; tainted outputs excluded; sheet label left else above; carry-forward rule; `0.0%` shows
  11.5% and edits as 11.5; step defaults; 3 x 3 under 480 px.
- **Measurement (a script run once, recorded in the task report):** an at-cap workbook (100,000 cells, 20,000 formulas): SheetJS
  read, IronCalc load + evaluate, graph + diff time and peak RSS in Node; one wasm `evaluate()` after one input change. Over 60 s
  or 1 GB in Node: lower the caps (`limits.ts` and spec s4.5, same commit). Over 250 ms in wasm: Task 3 builds the Web Worker (D18).
