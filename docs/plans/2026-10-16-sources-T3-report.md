## Decisions and deviations (read these)
1. **Migration 0026 edited again (not hosted).** The plan lists "the storage meter (count `source-thumbs`)" under Task 3, but that counter is SQL (`storage_usage()` reads only the `documents` bucket), and D108 ("sources do not count in the capture streak") needs `capture_days()` (public). Both are `create or replace` with one line changed, grants kept, tested in 0026's pgTAP. The hosted release is still exactly 0026 and 0027. The reviewer should re-read 0026 sections 6a/6b.
2. **A picture that fails for a reason that may pass is a failed try of the whole read** (retried, 3 tries), not a stored title with no picture. Only a picture over 200 KB is final (`too_big_image`, title kept). Non-JPEG bytes count as `unavailable`.
3. **Which problems are retried.** The pump reads only never-read links with fewer than 3 tries whose last problem is `timeout` or `unavailable`; `not_found`, `not_embeddable`, `not_page`, `refused`, `too_big_image`, `purged` wait for "Read again". `not_found` on a link that was read before is `gone`; on the first read it is only the problem sentence. The daily re-check takes only YouTube links read before, so a never-read dead link is not asked about every day. An `not_embeddable` re-check keeps the old data (purged at 30 days, never made gone).
4. **"Read again" cooldown (T2 binding note).** Never `fetched_at`. A read less than a minute ago by `checked_at` (the database, every instance), or a try less than a minute ago in this process's own map (a failed try writes no date, by design). A second instance does not see the map: worst case one extra 10 s read per press, admin only.
5. **Rule 3 on third-party text uses both figure pattern sets** (`PRICE_NUMBER` and the ledger set: a rupee amount, a percent with a verb of movement, "up 3x"), whatever the file's date, never allowanceable. This over-matches by design (an outside title "profit up 8%" is refused; untick the title). The message differs for a link ("Take the source off the file") because unticking does not help there.
6. **`outside` is required** in `LintInput` and `PublishContext` (the "decide for each surface" rule), so 17 test fixtures got `outside: []`. Tests changed only for that: the lint/publish/preview/words/seed/file fixtures, `clocks.test.ts`, `drain.test.ts` and `e2e/clocks.spec.ts` (the new step names in the expected lists), `trays.test.tsx` and `today.test.ts` (`isSource`), three `??
