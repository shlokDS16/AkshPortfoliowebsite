# Living Project Memory

Do not summarize away important information.

Instead:

- Append observations.
- Link related decisions.
- Preserve chronology.
- Maintain provenance.

When conflicting information exists, record both.
Never silently replace history.

Treat the project timeline as evidence, not documentation.

Every significant design decision should be traceable back to:

- the originating question
- the reasoning
- the alternatives
- the final decision
