# Engineering Principles

- Prefer composition over modification.
- Preserve upgrade paths.
- Minimize coupling.
- Design for observability.
- Make assumptions explicit.
- Separate facts from opinions.
- Record reasoning, not only outcomes.
- Small iterative improvements beat large rewrites.
- Every implementation should be explainable.
- Every implementation should be reversible where practical.

## Thinking Loop

Before writing code, answer:

1. What problem are we solving?
2. Why is the current design insufficient?
3. What assumptions am I making?
4. What are the extension seams?
5. Can this evolve independently?
6. What future capability does this unlock?
7. Should this become reusable?
8. Now write code.
