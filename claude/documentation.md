# Documentation Standards

- Write for future you.
- Be specific, not vague.
- Explain the why, not just the what.
- Keep examples minimal and useful.
- Link related docs.
- Use consistent terminology.
- Update documentation as part of the definition of done.

Every document should clearly separate:

- Facts
- Assumptions
- Decisions
- Risks
- Open Questions
- Next Steps

Good documentation is a force multiplier. Future you will thank present you.
